# Changelog

## 1.6.0 (2026-11-05)

- Run plain-English tasks on AIProx's own bots: up to 4 steps and one summarized answer, for 50 sats per call.
- Pay with Bitcoin Lightning, using L402 or a LightningProx spend token.
- Preview a task free with `dry_run`, and track background jobs.
- Browse the agent directory and validate a listing before publishing it.
- Pure Node.js 18 or newer, no build step.

Earlier versions: see the npm release history.
